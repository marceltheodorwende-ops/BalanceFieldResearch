# Fresh-origin subset and its continuation

Date: 3 November 2026. Existing research-stage supplement. No new paper, event law or physical rule is adopted.

## 1. Result

A fresh-origin subset with `rho_F,0=(-lambda_0)Pi_0` and `rho_W,0=Pi_0` is mathematically consistent with the existing finite state category and event. On this subset the witness has no independent initial coordinate once K is supplied. This restriction does **not** make the witness redundant in the general state category.

The existing transport preserves equality of the witness and normalized formation whenever there is no new seed and a nonzero common inherited packet survives. A genuine orthogonal formation seed breaks that equality. An explicit fresh-ground-state input to the unchanged event demonstrates the break after one step.

However, the absence of a predecessor does not mathematically select this subset. The reviewed source clauses give formation minima, primitive identity and inherited continuation, but have not established their unique origin identification. The subset is therefore a **conditional initial-state restriction**, not a newly proved consequence of all original BFG assumptions and not a default added to the program.

## 2. Precise subset and parameter count

Let K have simple negative lowest eigenvalue lambda_0 and ground projector Pi_0. Define a candidate subset of the existing typed category by

```math
\mathcal O=\{(K,(-\lambda_0)\Pi_0,\Pi_0,Y,P):
Y>0,\ P=P^*=P^2\}.
```

One may separately restrict `Pi_0<=P` if support of the initial witness in persistence is required. This is explicit, rather than silently derived. Y and P remain supplied coordinates. Membership in this typed subset does not guarantee a successful first event: selection, load and seed gates still apply.

On O, forgetting W loses no information, because its value is already a function of K. This is a restriction of the initial-state set, not a theorem that deleting W from every state preserves deterministic evolution. Nor does it derive K's capacity inputs, Y's initial interface or P's origin rule.

For any fresh nonzero rank-one density, `rho_F/tr(rho_F)` is the unique projector onto its line, as proved in the previous audits. Equating that derived profile identifier with the identity role is precisely the boundary identification being examined. Defining O proves that the identification is consistent; it does not prove that every BFG origin belongs to O.

## 3. Exact common-transport theorem

Suppose F>=0, f=tr(F)>0, and W=F/f. Let T be a finite rectangular map used for both inherited packets. Let A=TFT* and a=tr(A)>0. The retained witness mass is m=tr(TWT*)=a/f. Therefore

```math
W_+=\frac{TWT^*}{m}=\frac{A}{a}.
```

If no formation seed is added, F_+=A and hence `W_+=F_+/tr(F_+)`. The result requires neither an isometric T nor an unchanged carrier dimension. Consecutive successful selection and transport stages obey the same identity when their normalization masses are handled consistently. No preservation is asserted across a zero-mass gate.

Now let the existing event add a positive seed S of positive trace s with orthogonal support to A. It sets

```math
F_+=A+S,\qquad W_+=A/a.
```

Let E project onto the seed support. Then `E W_+=0`, whereas
`E F_+/tr(F_+)=S/(a+s)!=0`. Thus the two normalized operators differ. This is exactly why a root-only identification is compatible with later two-density separation. On the source's genuinely emergent complement, A and the seed have the required orthogonal supports.

In fact, writing U=S/s, orthogonality gives the exact Hilbert–Schmidt diagnostic

```math
\left\|\frac{F_+}{a+s}-W_+\right\|_F^2
=\left(\frac{s}{a+s}\right)^2
\left(\operatorname{tr}(W_+^2)+\operatorname{tr}(U^2)\right)>0.
```

This quantitative identity measures the separation; it is not a new evolution law. The argument applies to the two-density inheritance/seed stage and to successful preceding common selection. The actual preserved helper is also tested below on a well-separated case.

## 4. A fresh-origin event that separates the two roles

Take exact initial data

```math
K=\operatorname{diag}(-2,-1),\quad
\Pi_0=\operatorname{diag}(1,0),\quad
F=2\Pi_0,\quad W=P=\Pi_0.
```

This F is the actual fresh quartic minimum's density, rather than an arbitrary rescaling of the profile.

First set `Y_a=I/4`. Selection retains all modes; Y commutes with P. Both analysis branches have only the first input direction, so the active next carrier is one dimensional. There is no emergent complement and no seed. The successor has `F_+=2`, `W_+=1`, `K_+=-2`, and

```math
Y_+=\frac{2(1/4)^2}{(1+1/4)^2(1+(1/4)^2)}=\frac{32}{425}.
```

Now set

```math
Y_b=\begin{pmatrix}1/4&1/8\\1/8&1/4\end{pmatrix}.
```

Its eigenvalues are 1/8 and 3/8, so selection again retains all modes. With G=I+Y and the graph projector onto the first line,

```math
P_G=\begin{pmatrix}1&1/10\\0&0\end{pmatrix},\qquad
P_GC=\begin{pmatrix}4/5&0\\0&0\end{pmatrix},\qquad
P_GB=\begin{pmatrix}1/5&1/10\\0&0\end{pmatrix}.
```

The two loads are positive, so both analysis weights are positive. The stacked analysis has rank two, while every target row lives in a copy of the old first direction. Consequently the transported K is `K_+=-2I` on the two-dimensional active target. The inherited packet has rank one, trace a=2 and projector S_inh; the one-dimensional emergent complement has the simple negative eigenvalue -2 and produces seed `2(I-S_inh)`.

Therefore the existing event gives, in any active orthonormal gauge,

```math
F_+=2I,\quad \operatorname{tr}F_+=4,\quad
W_+=S_{\rm inh},\quad
F_+/\operatorname{tr}F_+=I/2\ne W_+.
```

The squared Frobenius separation is exactly 1/2. Both outputs have full persistence on their respective active carriers. This shows that even a fresh-origin input with minimal initial protected line can leave the equality subset when neutral geometry does not commute with that line. No alternative successor rule or extra seed was inserted.

The isotropic case is not evidence that every origin remains scalar, and the second case is not evidence that nature realizes either coupling. Y remains an explicitly varied initial input.

## 5. Why the boundary condition is not yet forced

Absence of ancestry says there is no earlier overlap equation to apply. It does not add an equation identifying a normalized witness with the current profile. In the existing general typed category, the same fresh F, K and Y with P=I permit both W=Pi_0 and W=I/2. Labelling either state 'first' does not alter its algebraic constraints. This compares only that stated packet, not every historical axiom.

If P=Pi_0 is independently justified **and** the witness is required to be supported inside P, positivity and normalization do force W=Pi_0. Thus the root question can be reduced to an origin persistence/support justification; it has not vanished. Insisting on these two premises without a source argument would introduce the missing restriction by hand.

The inherited continuation cannot create the origin from zero predecessor support: its polar overlap is zero, its retained mass is zero, and the existing gate terminates. An origin constructor is a boundary operation on nonempty formation data; it is not obtained by applying the ordinary event to its absorbing terminal state. No boundary operation is implemented here.
