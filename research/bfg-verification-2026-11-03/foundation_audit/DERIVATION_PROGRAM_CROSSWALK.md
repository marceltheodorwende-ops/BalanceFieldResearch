## Typed bridge: why the existing Gram derivation does apply conditionally

Use T:H_source -> H_neutral for the channel of the earlier quadratic completion, to avoid confusing its name with an event's analysis A. Let the program's declared A_event:H_n -> H_n direct-sum H_n be the channel substituted for T. This is a valid instance of that completion once the role and equal target metric have been specified. Minimizing gives retained form `(I+A_event* A_event)^-1` on the source. Identifying that retained form with the same neutral response determines the source load uniquely. If A_event=U Sigma V*, its source load on Ran(V) has V-coordinates Sigma^2; its target load on Ran(U) has U-coordinates Sigma^2. The program correctly stores the latter r-by-r matrix.

This is not a free coordinate trick that proves an arbitrary physical identification. It is the exact conditional argument already available in the prior bridge and unified theorem. The channel's construction and its use as this next event's neutral assessment remain the explicit premises.

## Why the 8/45 versus 8/53 witness is excluded here

For the program's scalar example the source Gram is s=8/45. The existing completion therefore gives retained response `1/(1+s)=45/53`. Replacing s by h(s)=8/53 gives response `53/61`, differing by `64/3233`. Thus the alternative does **not** realize the same retained form for the same fixed channel and metrics. It satisfies the weaker packet P in the prior audit and fails the stronger same-completion premise. It is not a counterexample to the existing conditional derivation. Both findings are compatible.

## Seed derivation that must not be discarded

For a fixed Hermitian emergent block with lowest eigenvalue lambda0<0, the original quartic functional satisfies, with r=||delta||,

`F(delta) >= lambda0 r^2/2 + r^4/4 = (r^2+lambda0)^2/4 - lambda0^2/4`.

Equality is attained on a ground eigenvector with r^2=-lambda0. If the ground is simple, every real minimizer differs only by sign (complex minimizers by phase), and its density is uniquely `(-lambda0) Pi0`. The seed magnitude therefore has a genuine conditional derivation from the existing formation functional. What remains an event-level prescription is using the emergent K_E as that formation input and terminating rather than choosing among degenerate ground directions. This follow-up clarifies the earlier ledger's compressed wording; it does not invent a new seed law.

## State reduction: matching formulas is not recovering all roles

The old master state retains three capacities and an R_C operator; the November state retains their combined K and an ordinary P. Common compression commutes with the linear combination K=c+aleph-D, so the kernel formula is consistent. However, distinct positive capacity triples can have the same K, and P alone does not recover the contracting complement of R_C. The source/operator dimensions also change at events. This audit establishes the listed algebraic correspondences; it does not assert a proved lossless state equivalence or a complete commuting diagram for every rank-changing master-state implementation.

## Final status

Already established: a BFG-internal conditional derivation of the neutral resolvent, source Gram and active-target Sigma^2; conditional selector and weight identities; the formation minimizer underlying the seed; and finite-event theorems once the event rules are specified. No external sector equation is required for these algebraic steps.

Still distinct: whether the precise quadratic completion, carrier/metric identification, gain meaning, cross-fed analysis, emergent-block role and projection order are forced by the earlier primitive premise set. The September proposed L0-NC rule fixes one tangent channel only if adopted; it remains labelled proposed and is not silently used here.

The correct next research question is therefore about those narrowly identified premises, not whether the already computed resolvent or Gram algebra needs to be rediscovered. No model rule is changed by this reconciliation.
