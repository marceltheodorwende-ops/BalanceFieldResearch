# Does the source origin supply the information data and local profile domain?

Date: 3 November 2026. BFG-Engine source follow-up in the existing verification stage. No new physical law, paper or initialization rule.

## 1. Source finding: there is an upstream information formula

The plugin's **Constructive Structured Level-0 Foundation**, Section 14, PDF page 20, explicitly defines

```math
C_\theta^{N_0}(X)=\{Y:\Xi_{\rm cfg}^{N_0}(X,Y)\ge\theta\},
\qquad I_{N_0}(X)=\log|C_\theta^{N_0}(X)|.
```

The actual PDF page was rendered and visually inspected. Thus it would be wrong to describe the source information merely as an unnamed scalar. It has a conditional configuration-count formula. Once the comparison domain, similarity functional and threshold are specified, the finite class count and information value are determined. The inspected formula does not itself supply those objects uniquely from the quartic formation operator.

The **Neutral Interface**, Section 7.1, supplies a different-level realization `I[s]=s*J s`. The **Strongest Version**, Sections 24.1–24.2, additionally requires nonnegative finite information with a well-defined feedback derivative, and its Sections 61.6–61.7 give field dynamics. These are genuine source relations. None of the inspected passages establishes that the Level-0 count is the same quadratic functional on the previously constructed local complex probe family without a representation map and compatibility conditions.

The earlier 20-reference global plugin context is retained; this step directly checks the Level-0 information clause, its domain and the finite formation gate. It is not a fresh full proof audit of every plugin document. [SOURCES.json](SOURCES.json) pins the source hashes and locations.

## 2. What the count formula determines, and what remains input

On a fixed four-configuration domain, take one similarity functional to encode the partition `{a,b},{c,d}` and another to encode `{a,b,c,d}`. Set similarity to one inside each partition block, zero outside, with the **same** threshold 1/2. Both are reflexive symmetric equivalence-based comparisons. At the same configuration a, the information values are respectively log(2) and log(4).

This compares the source's count definition and generic comparison roles, not every BFG origin axiom with every other datum fixed. Its purpose is precise: supplying the formula without the similarity structure does not supply a numerical value. A stronger source condition could select the similarity; its derivation would be needed. The logarithm base is held fixed greater than one, so this is not a mere change of units/base.

For an infinite comparison domain, the source cardinality expression additionally needs a finite value or a justified alternative realization before it can equal a finite Hilbert quadratic form. No measure or averaging rule is inserted here.

## 3. Exact compatibility test for a proposed configuration-to-profile bridge

Suppose a proposed representation assigns source information values to unit Hilbert profiles. If those values are to equal `q(s)=s*J s` for one Hermitian J, they must obey quadratic identities. For orthonormal u,v and `s_+=(u+v)/sqrt(2)`, `s_-=(u-v)/sqrt(2)`,

```math
q(s_+)+q(s_-)=q(u)+q(v).
```

This is a consequence of expanding the quadratic form, not an extra physical axiom.

Take five profile labels `u,v,s_+,s_-,s_i=(u+i v)/sqrt(2)` and assign configuration-class sizes `2,2,4,2,2` respectively. These counts are realized exactly by a finite equivalence partition with block sizes `2,2,4,2,2`. The count definition is internally satisfied. But the displayed quadratic identity has discrepancy

```math
\log4+\log2-\log2-\log2=\log2\ne0.
```

Therefore no Hermitian 2x2 J realizes **that candidate assignment**. The real-linear measurement matrix has rank four while its augmented value matrix has rank five. This does not refute Level-0 information; it shows why the proposed Hilbert identification must be proved rather than assumed.

A positive control uses five blocks of size two. All five values are log(2), the equations are consistent, and the unique Hermitian reconstruction is `J=log(2)I`. Thus the test accepts compatible data instead of simply rejecting the idea of a bridge.

The exact validator in `check_origin_information.py` uses only class counts and the quadratic source realization. It does not call synthetic values measurements of nature or values already derived for the actual BFG origin.

## 4. A conditional restriction from finite class counts

There is a stronger implication. Assume an exact same-value bridge assigns the count information from a **fixed finite comparison domain** to every unit profile in a connected open patch. The count values form a finite set `{log m}`. A quadratic q is continuous, so its image on the connected patch is connected. A finite connected subset of the real line is a singleton. Hence q is constant there, say c.

The local information-identifiability theorem then applied to `q(s)-c||s||^2` gives

```math
J=cI.
```

Thus that particular exact finite-count/open-patch bridge can only produce an isotropic information operator. It cannot give a general anisotropic J. This is a theorem about the explicitly stated bridge hypotheses, not a universal assertion that BFG information is isotropic. A different coarse-graining, nonfinite realization or additional map could have different properties, but none is silently invented here. Even the isotropic case still needs the class size, comparison structure and log convention to specify c.

## 5. Does the first formation itself supply the profile family?

The September 22 finite **real** formation theorem has exactly the two fresh minimizers `+/-sqrt(-lambda_0)e_0`. After phase-free normalization, both give the same projector Pi_0. Its profile-projector span has rank one. The finite complex extension also has only the same line after removing global phase. For n>1, the exact fresh minimum set alone is therefore not the n^2-direction family needed for a general information operator. In dimension one the operator has only one scalar component, but its information value still needs to be supplied or derived.

This does not say that the full BFG admits no perturbations. The later source admits balance/interface corridors and recursive states; the November finite event has a larger typed state domain. Their perturbations are not automatically additional exact minima of this particular first formation problem.

The distinction can be quantified without adding dynamics. Keep the formed amplitude and take

```math
d(w)=\sqrt{-\lambda_0}\frac{e_0+w}{\sqrt{1+\|w\|^2}},\qquad w\perp e_0.
```

For the existing quartic functional F,

```math
F(d(w))-F_{\min}
=\frac{-\lambda_0}{2}
\frac{w^*(K-\lambda_0I)w}{1+\|w\|^2}>0\quad(w\ne0).
```

The source gap proves strict positivity. If `L=lambda_max(K)-lambda_0`, then

```math
\frac{(-\lambda_0)\Delta}{2}\frac{\|w\|^2}{1+\|w\|^2}
\le F(d(w))-F_{\min}
\le\frac{(-\lambda_0)L}{2}\frac{\|w\|^2}{1+\|w\|^2}.
```

For the local probe construction with ||w||^2<=2t^2, the upper bound is at most `(-lambda_0)L t^2`. A **supplied positive formation-cost budget** could therefore accommodate sufficiently small probes; the strict minimum condition does not. No such budget is adopted as an origin admissibility law. Complex w additionally requires the justified complex sector; the original real formation theorem alone allows only real w.

For K=diag(-2,1), a transverse w=t e_1 gives exact excess `3t^2/(1+t^2)`. It is positive at every t>0; at t=1/20 it is 3/401, below a hypothetical budget 1/100 but still not an exact minimum.

## 6. What an admissible neighborhood would still require

The source's approximate balance and interface bands can provide slack in specified regimes, but no blanket conclusion follows that the first admissible origin set is open in all complex directions. Such a conclusion requires the actual carrier, continuity/strict margins of the relevant constraints, the bounded-recursion domain and compatibility with any exact constraints. The earlier local-information theorem proves a conditional reconstruction once that family and its functional values are available, not their initial existence.

In particular, a source permission to vary N is not itself a proof that all nearby state profiles are allowed. State variation, operator variation and dynamical reachability are separate assertions. Nor do the field equations remove the need for field data, coefficients and an origin-to-Hilbert representation.
