# Persistence Inclusion Theorem and Exact-Stratum Gap

## 1. Theorem

Let

\[
G=I+Y>0,
\qquad
C=G^{-1},
\]

and let \(W\) be the finite persistent subspace with basis matrix \(Z\).

Its \(G\)-orthogonal projector is

\[
P_G
=
Z(Z^\dagger GZ)^{-1}Z^\dagger G.
\]

Assume both reciprocal loads are positive, so the inherited branch has positive
weight \(\alpha>0\).

The cross-fed analysis operator contains the branch

\[
\sqrt{\alpha}\,P_GC.
\]

Then

\[
\boxed{
W\subseteq \operatorname{Ran}A^\dagger.
}
\]

### Proof

Because \(G\) is Hermitian positive,

\[
P_G^\dagger
=
GZ(Z^\dagger GZ)^{-1}Z^\dagger.
\]

Since \(C=G^{-1}\),

\[
CP_G^\dagger
=
Z(Z^\dagger GZ)^{-1}Z^\dagger.
\]

The right-hand side has range exactly \(W\).

But

\[
A^\dagger
\]

contains the block

\[
\sqrt{\alpha}\,CP_G^\dagger.
\]

Therefore

\[
W
=
\operatorname{Ran}(CP_G^\dagger)
\subseteq
\operatorname{Ran}A^\dagger.
\]

q.e.d.

## 2. Consequence for witness transport

Let

\[
S_A=P_{\operatorname{Ran}A^\dagger}.
\]

The theorem gives

\[
S_A P_W=P_W.
\]

Hence for every normalized witness supported in \(W\),

\[
\rho_W=P_W\rho_WP_W,
\]

one has

\[
\operatorname{tr}(S_A\rho_W)=1.
\]

Therefore the exact algebraic active-support transition generated by this cross-fed
operator cannot partially or completely destroy the inherited persistent witness.

\[
\boxed{
m_{\rm keep}=1
}
\]

for the exact generated active support.

## 4. Relation to R4

R4 is more general as a **continuation theorem**.

It accepts already-declared source and target projectors \(Q_-\) and \(Q_+\) and then
constructs

\[
T=\operatorname{polar}(Q_+Q_-).
\]

It therefore correctly handles rank decrease, rank increase, rotating supports and
discontinuous overlap.

But this theorem does not imply that the exact cross-fed BFG analysis operator itself
generates every such \(Q_+\).

The R4 runtime defines practical active/persistent support projectors using spectral
thresholds. Those thresholds are appropriate numerical/runtime declarations, but a
BFG-only fundamental field law cannot silently promote a floating implementation
tolerance into a universal physical constant.

## 5. Exact-stratum gap

If the final TOE is required to generate genuine persistent-rank decrease or
discontinuous persistent overlap, one additional exact BFG mechanism is required.

Call it

\[
\boxed{
\mathcal S_{\rm BFG}
}
\]

—the exact stratum-selection law.

It would have to decide, from the BFG state itself and without a floating numerical
tolerance, which previously persistent directions remain peripheral at the next step.

The current inherited-preservation recursion rule

\[
R_{C,+}
=
P_+
+
(I-P_+)C_N(Y_+)(I-P_+)
\]

does not do this, because every direction placed in \(P_+\) is fixed at unit modulus.

Therefore there are now two logically distinct research options:

1. **Persistence-conservation principle:** accept \(p_{n+1}\ge p_n\) as a fundamental
   BFG prediction, with loss occurring only at terminal/no-choice failure; or
2. **Dynamic stratum principle:** derive a new exact BFG selector
   \(\mathcal S_{\rm BFG}\) that can demote previously persistent modes.

This choice must be made mathematically before using R4 rank-decrease examples as
evidence for the universal master law.
