# Scientific scope

BFG Emergence Studio preserves the distinction made in the BFG corpus
between mathematical closure and natural realization.

## Generic core
The software treats exact neutral resolution, persistent support, reciprocal
order, polar support transport, formation, terminal failure, and inherited-
support novelty as the generic BFG grammar.

## Numerical layer
Finite precision requires explicit tolerances for spectral equality, rank,
positivity, and peripheral eigenvalues. These are numerical tolerances only,
not free parameters of the exact BFG generator.

## Carrier layer
The BFG universal reclosure paper writes the next positive geometry through
carrier-dependent Gram ingredients. Therefore the software makes reconstruction
pluggable. `ReferenceGramCarrier` is only one deterministic demonstration.

## Empirical layer
A real application needs an independently specified mapping from measurements
to a BFG carrier and independent validation. The software does not itself prove
physical, biological, cognitive, or other natural realization.


## Self-organization carrier

`SelfOrganizingNetworkCarrier` is a concrete exploratory realization. It maps
BFG formation activity into resource redistribution and relational graph
rebuilding. The neutral geometry and persistence geometry are constructed from
the same graph operator so the carrier remains on the controlled `[P,Y]=0`
support stratum.

Organizational quantities such as maintenance score, multi-cluster state, and
`split_like` lineage events are software observables / heuristics, not universal
BFG theorems and not evidence of biological life.


## Population and fission layer

The population module introduces carrier-specific rules for:
- node birth by resource splitting,
- node loss below a resource floor,
- viable-component fission,
- independent child-unit identities and subsequent BFG trajectories.

A fission is stronger than the earlier `split_like` diagnostic because the
children are instantiated as separate dynamical systems. It is still a
**software reproduction analogue**, not evidence that biological reproduction
is derived from BFG.

Node-birth, node-loss, resource thresholds, and component viability thresholds
belong to the exploratory carrier model. The BFG core formation and reclosure
gates are not relaxed to make those events occur.


## Evolution layer

The evolution module adds three carrier-specific mechanisms above the generic
BFG core:

1. inheritance of a bounded parameter vector at independent-unit fission;
2. stochastic bounded mutation of that inherited vector;
3. differential survival when candidate population exceeds carrying capacity.

The mutated parameters are used to reconstruct each child's subsequent
`K`, `Y`, `R_C`, resource dynamics, topology dynamics, birth threshold, and
fission threshold. Therefore inheritance has causal effect on later software
trajectories.

The selection observable is intentionally documented as a carrier-level
heuristic. It does not claim that biological fitness, Darwinian evolution, or
natural selection has been derived uniquely from the universal BFG equations.
What is demonstrated is that BFG-admissible independent units can support a
computational inheritance–variation–selection loop.


## Environmental adaptation layer

Environmental programs are carrier-level experimental conditions. They affect
resource availability and relational disturbance before BFG reclosure and can
change carrying capacity and preferred heritable trait values.

`trait_match` and the environment-weighted selection score are operational
software observables, not universal BFG equations. The generic BFG formation,
neutral resolution, persistence, and reclosure gates remain unchanged.

A reported adaptation gain therefore means: within this declared carrier and
environmental model, differential survival and subsequent inheritance move the
population's heritable parameter distribution toward the active environmental
target while BFG admissibility continues to hold. It is not an empirical claim
about biological adaptation without an independently validated carrier map.


## Learning and memory layer

The learning/memory module is a downstream carrier realization, consistent
with the BFG universal-reclosure distinction between universal invariant
coordinates and cognitive labels.

The implementation tests two target-independent signatures:

- **Adaptive plasticity:** transverse carrier policy changes while the
  underlying inherited trait vector remains fixed.
- **Witness persistence:** a prospectively formed contextual trace remains
  recoverable when the context reappears after separated recursive cycles.

Within-lifetime policy change is bounded by `max_policy_step`; memory capacity
is finite; memory traces decay; highly similar traces are compressed; and
surplus traces are exported/forgotten. This prevents arbitrary policy jumps
and unbounded memory growth.

The memory-disabled control is essential: a claim of learning is not inferred
merely from internal state change. The reference benchmark requires later
transition behavior to differ prospectively and compares reward to a carrier
with the same environment but without retained memory/policy.

The scalar reward, contextual cue representation, exploratory probe mechanism,
memory capacity, and policy coordinates are carrier-specific model choices.
They are not asserted to be universal biological or neural mechanisms.


## Self-model layer

The self-model module is a downstream carrier realization of BFG
self-reference, not a new universal generator term.

The module separates:
- world readout,
- organism/self-state readout,
- their mediated closure,
- a prospective predictor of the organism's own next persistent state,
- policy feedback from that prediction into later carrier action.

A self-model closure flag requires more than monitoring. It requires preserved
world/self distinction, nonzero mediation, bounded recursive dynamics,
prospective learning, and a closed causal self-reference path that reaches
later organism state through action.

The ablated control still receives the same world sequence and lower learning /
memory machinery, but model-based action selection is disabled. This prevents
the presence of an internal regression object by itself from being counted as
self-model closure.

The predictor, readout coordinates, thresholds, and candidate-policy search are
carrier-specific implementation choices. A successful software result does not
establish consciousness, subjectivity, phenomenal awareness, or biological
selfhood. Those would require additional BFG closure stages and independent
empirical realization tests.


## Perspective layer

`Perspective Closure` is implemented as the Level-29 downstream carrier layer
after Self-Model Closure.

Its source-grounded target is the mediation of multiple current
self-representations into one persistent standpoint while preserving relevant
differentiation. The software therefore measures both sides:

- multiplicity: diversity among separately retained self-representations;
- unity: distance from those representations to the persistent standpoint.

A result is not counted as successful perspective merely because a mean vector
exists. Closure also requires a bounded multiplicity/unity corridor,
persistence, noncollapse of the representational basis, and bounded recursive
dynamics.

The perspective mediator, seven-coordinate common embedding, compatibility
weighting, export threshold, and weak action-coupling coefficient are
carrier-specific operational choices. They are not claimed to be uniquely
derived neurobiological mechanisms.

`Here(t)` is reported only as an organizational standpoint coordinate, following
the BFG source distinction from ordinary spatial position.

Perspective closure remains distinct from later Identity, Consciousness,
Phenomenal Unity, and Selfhood closures. No successful Level-29 run should be
interpreted as evidence that those later closures have already been realized.


## Identity layer

Identity Closure is implemented as the Level-30 downstream carrier layer after
Perspective Closure.

The source-grounded invariant target is bounded temporal continuity:

`epsilon_Id < d_NId(Selfpast, Selfnow) < L_Id`

with recursive boundedness and finite Identity persistence. The software
therefore rejects both temporal fragmentation and complete rigidity.

The additional universal-realization diagnostic is a persistent self-index
under transverse carrier adaptation. The software reports these separately so
a high continuity score cannot be obtained merely by freezing all change.

Historical-coordinate export is a carrier implementation of the Level-30
excess channel. It permits obsolete historical structure to cease constraining
the present self without erasing the entire Identity witness.

The specific seven-coordinate Identity carrier, numerical corridor bounds,
recurrence coefficient, and export threshold are declared implementation
choices. They are not claimed as uniquely derived biological or psychological
constants.

Successful Identity Closure does not establish Consciousness Closure. The
latter requires additional source-defined world/self appearance conditions and
remains outside the current frozen theory stack.

## Theory feature freeze boundary

The implemented theory stack is frozen at Identity Closure for the next
development phase. This is a project-engineering decision, not a BFG theorem.

The purpose is to prevent feature accumulation from outrunning falsification.
Subsequent work should prioritize:
- reproducible benchmark suites,
- numerical sensitivity and randomized robustness testing,
- persistent experiment/session state,
- carrier SDK hardening,
- performance scaling,
- independent real-domain carrier mappings and no-retuning validation.

Higher cognitive/phenomenal closure names remain documented source hypotheses,
not implemented achievements.


## Software validation and hardening

The frozen theory stack is now accompanied by two distinct validation layers.

**Reference benchmarks** test expected software behavior on fixed declared
seeds and controls. They protect against regressions in the implemented
mathematical / carrier logic.

**Robustness audits** use randomized algebraic instances, commuting controls,
noncommuting controls, numerical-tolerance sweeps, invalid-input guards, and
carrier-parameter perturbations.

Passing these software tests supports implementation stability. It does not
convert software consistency into empirical evidence for natural realization.

## Provenance and persistence

Experiment manifests fingerprint the full `bfg_studio/*.py` source tree and
record the numerical environment and declared parameters.

Core BFG states use NPZ + JSON rather than pickle. The saved array file is
SHA-256 checked before loading. This provides an auditable save/load/resume
path for finite-dimensional core trajectories.

Higher-level runs persist frames, events, summaries, and provenance. Exact
mid-run restoration of every downstream population/cognitive object is not
claimed merely because its audit ledger can be reloaded.

## Carrier SDK and real-domain validation

The Carrier SDK separates three claims:

1. a measurement mapping is well-formed as software,
2. a fixed mapping survives no-retuning held-out comparison,
3. a natural system empirically realizes the BFG interpretation.

These are not equivalent.

`CarrierSchema` freezes the measurement mapping and invariant parameters by
fingerprint. `HeldoutValidationPlan` freezes the empirical split, null model,
primary metric, and success criterion before held-out evaluation.

The master build intentionally contains no fake "validated real carrier."
The first external carrier must be independently justified and evaluated under
the protocol in `REAL_DOMAIN_VALIDATION_PROTOCOL.md`.




## Annual sunspots: active readiness-first hypothesis

The active annual-sunspot carrier uses the full bundled 1700–2008 annual series
as development data under the same readiness-first policy used for CO2.

Three non-overlapping expanding-window preflight blocks are evaluated inside the
development record:

- 1860–1909,
- 1910–1959,
- 1960–2008.

All three folds favor the BFG feature family over the equal-coefficient matched
ordinary-feature null. Mean relative RMSE improvement is about +2.270%, the
worst fold remains positive at about +0.469%, and canonical reclosure succeeds
on 100% of fold states.

The active status is `READY_FOR_VALIDATION`.

The prospective claim is frozen against annual continuation data for 2009–2025.
Those target metrics remain unevaluated in the current master.

## Readiness versus confirmation

The software now distinguishes exploratory model development from confirmatory
empirical testing.

Calibration-only negative iterations are engineering evidence and may stay in
design logs rather than headline project summaries. This does not permit
deletion or reinterpretation of an already opened confirmatory held-out result.

A `READY_FOR_VALIDATION` carrier has passed a calibration-only readiness gate;
it has not yet passed its empirical held-out hypothesis.

Both the refreshed annual-sunspot carrier and the Mauna Loa CO2 carrier now
have this readiness status. Their prospective held-out target metrics remain
sealed.


## Portfolio-level empirical governance

Empirical carrier results are now governed by an explicit state machine.

`EXPLORATORY` and `NOT_YET_VALIDATED` are development states.
`READY_FOR_VALIDATION` means only that a prospective readiness gate passed.
`CONFIRMED` and `REJECTED` are immutable terminal outcomes for the frozen
mapping / held-out plan.

The Blind-Heldout Guard is an engineering control, not statistical evidence.
Its purpose is to prevent accidental leakage, post-readiness source drift, and
silent re-use of a confirmatory opening.

A seal binds the current source fingerprint and all material frozen carrier
artifacts. A one-time confirmation permit is deliberately separate from the
readiness token.

This architecture reduces accidental researcher degrees of freedom but does
not eliminate the need for sound external experimental design.


## ENSO carrier and cross-domain analysis

The third active real-domain carrier uses NOAA Pacific monthly sea-surface
temperature and models development-time SST anomaly relative to a
training-only monthly climatology.

It reaches `READY_FOR_VALIDATION` under the same portfolio readiness rule as
the other active carriers. Its prospective 2011–2025 target block remains
unopened.

Cross-domain analysis is explicitly restricted to each carrier's allowed
development/calibration period. It compares BFG internal coordinates rather
than assuming comparable physical units across domains.

A common q10–q90 interval across three development carriers is reported only
as an **exploratory shared carrier-coordinate corridor**.

It is not called a universal empirical invariant unless later independently
frozen held-out confirmations reproduce the structure without retuning.

The current absence of a three-domain shared q10–q90 corridor for spectral
mismatch is retained as a domain distinction, not normalized away.
