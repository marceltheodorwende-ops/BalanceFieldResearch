# Earlier executable laboratory

The network laboratory and dated finite models are retained for reproducibility. They are not relabelled as implementations of the new full canonical architecture.

From the repository root:

```sh
python -m unittest discover -s tests -v
python -m bfg_lab --output results
```

The dashboard in `results/network.html` describes synthetic network readouts. See the original [verification record](VERIFICATION.md), [formation and persistence proposal](PERSISTENCE_PROPOSAL.md), [network reference findings](REFERENCE_FINDINGS.md), and [reference stress findings](REFERENCE_STRESS_FINDINGS.md).
