Source format: https://www.edfplus.info/specs/edf.html . Header calibration is an instrument definition, not a BFG or physiological evolution law.

Scope: exact development manifest entry chb01/chb01_01.edf only for this checkpoint. No held-out or Siena EDF, no test annotation, no waveform payload, no full-dataset archive. contract.permit_eeg stays false. A separate narrowly bounded header probe must resolve an exact development manifest entry before any network request.

EDF layout: first256 bytes contain header length, signal count, number and duration of data records. Remaining256*nSignals bytes contain the grouped per-signal fields. Read bytes0–255, verify header_length=256*(nSignals+1), then bytes256–header_length-1. Enforce HTTP206 and exact Content-Range on both responses before reading their bodies, bound nSignals<=512 as a parser resource limit, refuse server responses that ignore ranges, disable redirects, and never read one byte past either requested range. Log header-byte counts/hashes; the original full EDF digest remains unverified until a later allowed full-file integrity check. A matching partial hash is not a full-file hash verification.

Parse ASCII numeric fields with exact rational arithmetic; record duration>0, signal sample counts>0, ordered digital/physical ranges. Preserve labels, physical units and declared rates; unknown auxiliary units are flagged, not silently treated as volts. Convert recognized V/mV/uV units by fixed SI prefixes. Calibration formula is x_phys=p_min+(d-d_min)*(p_max-p_min)/(d_max-d_min), in the declared physical unit. No signal filtering, covariance preparation or classifier here. Keep patient/recording identification bytes private; publish only selected non-identifying acquisition fields and provenance. Header dates alone do not establish contiguous recordings.

Candidate bipolar inputs require unique matching label and known voltage unit. Duplicate exact labels remain unresolved, never silently select the first, average channels or assume identical signal values. No unmeasured reference potential is reconstructed. Sample rate, units and label findings concern this record only; broadening to all565 development records needs a separately logged bounded metadata acquisition. Input/gap/QC/filter/model choices and physical BFG preparation remain OPEN.

Acceptance: synthetic EDF byte-fixture checks with hand-calculated calibration/rate; malformed/truncated/mismatched counts/ranges and oversized resource declarations rejected; strict range/redirect/held-out access refusal controls before real network use; real partial bytes match declared ranges and produce parsed findings; existing controls rerun; verified GitHub publication and ledger mirror.
