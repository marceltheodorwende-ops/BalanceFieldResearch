# EP01 causal streaming / recording boundary contract

Pre-implementation status: OPEN EP01 preprocessing dependency, not a frozen clinical protocol. Build an auditable execution primitive that prevents future-sample use, cross-file state leakage, silent sample deletion and fabricated gap filling. No waveform download or physiological/BFG evolution law is added.

Each instance processes exactly one declared uninterrupted EDF recording with known sample count, sampling rate, channel count and externally supplied fixed FIR coefficients. A new recording requires a new instance; exceeding the declared sample count fails. Every chunk supplies its first sample index, which must equal the next expected index; gaps/overlaps/duplicate chunks fail rather than concatenate or interpolate. EDF+D is not supported by this primitive until its discontinuous intervals are parsed. Hardware gaps not represented in metadata cannot be discovered by this mathematical contract. Cross-file timing remains unknown and is never inferred from adjacent file numbers.

At sample n, a valid output is y[n]=sum_{j=0}^{L-1} h[j]x[n-j], using only observed valid samples from the current recording. Coefficients are dimensionless, voltage stays in volts. No zero padding, whole-record centering, reverse-time filtering or fitted initial state. Until L valid samples exist, output is unavailable; after a supplied QC-invalid or nonfinite sample, history resets. QC thresholds themselves are not defined by this primitive. No cutoff, filter order or scientific coefficient vector is selected here; identity and short FIR fixtures are code controls only, not newly invented BFG laws or empirically optimized settings.

Return explicit ready/invalid masks and missing-value markers for unavailable output. Preserve all source sample indices and observed duration. Warmup and invalid samples remain in recording-time and reference-event denominators; they cannot be silently dropped to improve apparent sensitivity/false-alarm rates. Later alarm generation must treat unavailable outputs as no fresh detector activation/abstention and report coverage; the complete clinical abstention/uncertainty decision rule still requires freeze. A fail/truncated record is flagged, not silently excluded.

Signal sample n is indexed at n/fs; a conservative availability timestamp is (n+1)/fs, never a centered-window or backdated timestamp. This is an explicit acquisition/evaluation convention, not an independently measured device latency or the BFG event clock. Additional known device/compute latency would have to be included independently. Deadline/sensitivity choices remain separate evaluation definitions.

Acceptance: exact hand convolution, independent valid-run convolution oracle, chunk partition invariance, future-suffix invariance, correct end timestamps, reset across invalid samples and file boundaries, no silent gap/overrun/truncation, full observed-time accounting, finite coefficient/input controls and conditional error bound. Rerun prior controls and verify GitHub publication/ledger mirror. Clinical preprocessing/QC, actual acquisition coverage and BFG preparation/closure remain OPEN.

## Proof, numerical scope and checked implementation

Induction on sample index proves causality: before sample n the buffer contains only valid inputs with indices<n from this recording; appending x[n] and using the last L entries cannot depend on any x[m] with m>n. Reset removes all earlier history, so no invalid sample is used as a value or replaced by zero. Chunk boundaries do not alter this update, giving partition invariance for identical sample/QC sequences. Closing an instance and bounding its sample count prevent a second file from being concatenated into its state; a fresh instance begins with empty history. These are software/data-flow properties, not empirical brain dynamics.

Stability notion for this checkpoint: deterministic sup-norm output sensitivity of a FIXED finite FIR, on corresponding ready indices with identical QC masks and reset boundaries. For bounded additive perturbations ||e[n]||infinity<=delta, the triangle inequality yields ||sum h[j]e[n-j]||infinity<=||h||1 delta. The same argument gives ||y[n]||infinity<=||h||1 sup||x[n-j]||infinity. Delta is a hypothetical mathematical perturbation bound, not a fabricated sensor uncertainty estimate. Changing QC masks, timestamps, coefficients, montage, model or physiology is outside this bound. Numeric overflow fails the record and prevents continuation; no universal floating-point or clinical robustness guarantee is claimed.

Unavailable values carry NaN markers AND ready=false, never zero-filled samples. Consumers must honor the mask and preserve full time/reference-event accounting; this module does not itself compute seizure metrics or infer a QC threshold. The candidate 17-channel instrument mapper and subsequent waveform integrity/calibration are separate dependencies. No actual EEG filter is selected by the test fixture coefficients, and no BFG canonical update is modified.
