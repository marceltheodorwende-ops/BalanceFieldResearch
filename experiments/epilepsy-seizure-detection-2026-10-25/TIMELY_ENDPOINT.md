# EP01 timely endpoint: pre-implementation contract

Status: methodological implementation within OPEN EP01, not a confirmatory freeze or clinical result. Target: supplement pinned SzCORE scoring with original, unmerged clinical-event denominators and actual causal alarm activations. No new EEG or annotations required.

Statement: on one uninterrupted recording with finite positive duration T, disjoint half-open reference events [s,e), and disjoint nonadjacent alarm-active intervals [a,b), count a reference as timely detected iff a NEW alarm activation a satisfies s <= a < e and a <= s+D, for declared finite D>=0. Candidate D=30 seconds is a research design choice, not a clinical recommendation. No pre/post tolerance, merging, event splitting, artificial repeated activation or backdating. Alarm intervals must originate from logged availability times in a causal detector. Scoring cannot itself prove causality from supplied times.

Independently report: original event count; timely sensitivity; first within-event activation latency (including late); late detections; references with no fresh activation; activations outside all seizures per 24 total recording hours (false alarms); late ictal activations separately; alarm-active fraction and total activations/day. A late ictal activation is not falsely called a non-seizure false alarm. No-reference sensitivity is undefined/null. A sustained alarm beginning before a seizure does not provide a fresh timely activation. Occupancy and activation count expose always-on alarm strategies. All detector comparisons use the same D and records, without tuning on test.

Domains/edge rules: seconds relative to recording start, finite nonnegative endpoints, strictly positive interval durations, endpoints <=T; references ordered/disjoint, adjacent references permitted and never merged. Alarms ordered/disjoint/nonadjacent; adjacent active intervals must be represented as one interval. Reject invalid input rather than clipping. Exact event end is excluded; exact deadline is included only if before event end. Empty alarms/references allowed. D=0 permits activation exactly at onset. No conversion to coarse samples.

Matching: reference intervals are disjoint, so each activation belongs to at most one reference. First activation in a reference supplies its latency. All outside-reference activations count as false activations, even if a long active interval later overlaps a seizure. No ambiguous one-to-many TP credit. This supplemental endpoint differs deliberately from SzCORE's overlap/tolerance event units; retain both rather than substituting or silently changing benchmark definitions.

Recording gaps: call scorer separately for each uninterrupted observed segment, with local seconds. Never concatenate across missing time; no missing interval enters the denominator. A reference or alarm crossing a segment boundary cannot be silently clipped by this scorer (out-of-domain error). Real data boundary reconciliation, detector state reset and censoring rules remain an OPEN preprocessing dependency. Complete-record duration/coverage must be retained, not only seizure-containing portions. Aggregation sums sufficient statistics across segments/persons; uncertainty and final decision rules are not supplied by this checkpoint.

Acceptance before publication: analytic late-only, stale/always-on, no-event, exact boundary/deadline, long original events, adjacent references/alarms, invalid numeric/domain and false-rate controls; independent exhaustive oracle on generated small discrete cases; time scaling and added no-event-duration invariance checks; rerun existing24 controls. Synthetic intervals are code/mathematics controls, not observations. Completion means implementation and these checks plus verified publication; full EP01 remains OPEN pending data manifest, preprocessing, baselines, tuning, uncertainty/precision and frozen protocol.

## Derivation and implementation check

Disjoint half-open reference intervals partition a subset of [0,T). Each activation therefore belongs to zero or one reference, including adjacent references at their common boundary. Ordered activations permit a monotone reference pointer: discard references whose end <= activation; the remaining reference contains it iff its start <= activation. The first containing activation is the minimum within-event latency. Nonnegative latency <=D is precisely the stated deadline test; this implementation compares a-s to D, avoiding overflow of s+D. A reference receives at most one TP even if it has many activations. TP+late-event+no-fresh-activation counts equals original reference count. Outside-reference activations are counted independently; late ictal activations can occur even after an earlier timely activation and therefore are reported as activation counts, not event misses.

Alarm-active intervals are disjoint, so summing their lengths equals union duration; dividing by T gives occupancy. Rate = count*86400/T uses total observed seconds. Time scaling by c>0 preserves counts/occupancy and multiplies latency by c, while daily rates divide by c if deadline is scaled too. Adding background duration without new events preserves counts and decreases rates. These identities supply independent controls. Floating-point inputs must be representable finite seconds; unrepresentable integers or overflowing nonzero daily rates raise ValueError. Zero counts return finite zero even for very small T. No universal numerical robustness outside this stated representation is claimed.
