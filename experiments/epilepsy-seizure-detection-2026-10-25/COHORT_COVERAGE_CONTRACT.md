# EP01 manifest-first cohort completeness

Status: bounded completeness dependency implemented; EP01 OPEN. This is an execution/evaluation convention, not a biological or BFG law. No detector or clinical performance is established.

Contract: every expected record is specified before receipts with explicit person identity, known positive exact duration and original event count. This function requires those quantities; unknown metadata is a separate unresolved preparation dependency, never filled with defaults. Each manifest record must appear exactly once in the output. Absent receipt means missing; explicit failed receipt requires a reason. Unknown receipts, duplicate expected records, ambiguous statuses and scored identity/duration/event-count contradictions reject. Scored original event partition is checked against the expected reference count. Receipt content remains caller supplied; these consistency checks do not authenticate execution or provenance.

Construction: iterate over the expected manifest rather than available results. Sum duration and reference counts over all expected records, then report scored/failed/missing counts and unassessed duration/events per person. Thus adding or removing a result cannot remove the expected denominator. Partition into scored and unassessed subsets proves their durations and event counts add to the fixed expected totals. Explicit person aliases keep repeat sessions together; callers must obtain those identities from the validated split/manifest. No independence of files or generic biological interpretation is implied.

No failed or missing record is imputed as a true negative, silent detector, missed seizure or false alarm. Unknown detector output is not an observed zero. complete=true means only that all expected receipts passed the bounded consistency checks. cohort_performance remains null even when complete: patient-level metrics, uncertainty and final comparison require a separate fully specified aggregation/decision rule. Complete bookkeeping is not confirmation, adequate precision or clinical efficacy. Counts/rates on a scored subset must not be relabelled as whole-cohort performance.
