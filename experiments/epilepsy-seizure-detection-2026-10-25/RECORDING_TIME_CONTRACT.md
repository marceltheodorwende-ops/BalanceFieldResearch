# EP01 record-local time and annotation boundary

Status: implementation and conditional arithmetic verified; EP01 OPEN, no confirmation freeze or detector. Evaluation/instrument definitions only, not a BFG or biological law. Uses existing pinned chb01 summary and header; no new annotation access.

Statement: for a recording duration T>0, rate f>0 with Tf integral, and ordered original half-open intervals [a_i,b_i) satisfying 0<=a_i<b_i<=T and b_i<=a_(i+1), exact event time is S=sum(b_i-a_i), non-event time is T-S, and the full denominator is T. Disjointness proves additivity and 0<=S<=T. Adjacent events remain separate. Indices [fa_i,fb_i) are supplied only when both are integers. Otherwise original rational seconds remain, with sample conversion explicitly unavailable. No rounding, clipping, merging, reordering, exclusion or zero-event record deletion. No claim that original annotation precision equals physiological onset precision.

recording_time.reconcile implements this record-local boundary using exact rational values. Binary floats/bools are refused to avoid implicit precision assumptions; callers must supply explicit rational seconds. Unknown/out-of-bounds/overlapping events require source reconciliation instead of silent repair. This is not yet a complete annotation-file importer, a gap-aware scorer, or proof that all source annotations satisfy the assumptions. Availability/invalid time from causal_stream still requires explicit integration with clinical sensitivity denominators before freeze; this function never marks that time as seizure-free.

Inter-record clock nonidentifiability: let source end/start clock values be c_e,c_s. Without relative dates, possible elapsed gaps satisfy g=c_s-c_e+86400*k, for integer k consistent with chronology. Distinct k can give distinct nonnegative gaps while preserving the same clock text. Hence clock strings alone do not select a unique gap; chronological ordering does not supply the missing day count. clock_seconds supports source hour24 notation without imposing a day relation. Every result retains inter_record_gap_seconds=null and unresolved continuity. No concatenation or imputed non-seizure time is permitted from these strings. Dated EDF headers, acquisition provenance and annotation convention must be reconciled before any cross-file timeline claim.
