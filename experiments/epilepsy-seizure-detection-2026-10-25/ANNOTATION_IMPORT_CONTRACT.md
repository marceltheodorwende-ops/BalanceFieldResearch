Acceptance contract established before implementation: exact development filename membership, one block per file, exactly one ordered file start/end clock and declared event count, exactly that many complete ordered start/end pairs, no overlap/empty intervals, no silent unsupported lines, and no removal of zero-event files. Every block is tied to the existing development manifest and actual person alias. The pinned source loader verifies original bytes before decoding. The pure parser is explicitly restricted to the current unnumbered integer-seconds CHB summary dialect; unknown numbered/fractional variants fail and require a separately reviewed extension. Metadata parsing is not automatic permission to acquire other annotations or test data.

Construction: exact file-block grammar requires4+2n lines for declared n. Each pair must be Start then End and obey previous_end<=start<end. Induction yields ordered disjoint original events; count equality prevents truncated/missing pairs. Exact file paths prevent cross-file reassignment; duplicate paths reject. Source clock text is retained but does not define duration or cross-file elapsed time. Half-open intervals remain the explicit evaluation convention of recording_time, not a claim about physiological precision.

EDF join: exact path equality, known continuous EDF duration, explicit target sampling rate, then recording_time.reconcile bounds every event against that duration without clipping or rounding. The rate is caller-supplied and must come from the already-validated channel interface; this function does not independently validate electrode channels or enable waveforms. Without a matching header, duration_verified remains false. Clock differences are not substituted for EDF duration. Source event parsing alone does not validate annotation completeness, expert agreement, acquisition chronology or clinical seizure truth. Original annotations still require eventual independent format/endpoint provenance review before confirmation.
