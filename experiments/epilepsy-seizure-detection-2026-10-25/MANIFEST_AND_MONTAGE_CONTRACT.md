Proof of the criterion: if Lv=A(Bv), then Bw=0 implies Lw=0. Conversely, if ker(B) subset ker(L), the rule A(Bv)=Lv is well-defined on im(B) and extends linearly. The explicit midline vector violates the necessary condition, so no algorithm reconstructs the target uniquely without an additional assumption or measurement. A pseudoinverse would select an unobserved component offset, not discover it.
