## Explicit orientation rule and derived result

Before any model/data evaluation, the metadata compiler defines a fixed orientation rule: use a uniquely named direct channel when available. If no direct channel exists, use exactly one reverse-only label with sign-1. Multiple direct copies reject that target even if a reverse label is available; multiple reverse-only copies also reject. Reverse copies are not averaged with a direct copy. Sign is applied AFTER EDF physical-unit/offset calibration, not by negating raw ADC integers. In the allowed header, digital zero represents a nonzero physical offset, so raw negation would give the wrong orientation. Accepted label normalization changes only case, exterior whitespace and whitespace around '-'; it does not invent electrode aliases or infer wiring. Report original source indices, labels and signs.

For ideal electrode potentials the omitted edge satisfies the exact identity

T8-P8 = -(F8-T8) -(FP2-F8) +(FP2-F4) +(F4-C4) +(C4-P4) +(P4-O2) -(P8-O2).

Telescoping electrode terms proves this without fitting. Exact rational incidence checks show R B17=B18 and S B18=B17, with S R=I17; both incidence ranks are16. Therefore the two ideal measurement images are linearly equivalent on im(B18), although R S is not the identity on arbitrary18-vectors. Common electrode-reference shifts cancel. The signed path has coefficient1-norm7, so bounded per-channel errors <=delta imply reconstructed-path error <=7delta, attained by errors aligned with the coefficient signs. No actual sensor delta is asserted.

Concrete limit: an error vector with only the omitted18th target coordinate nonzero is annihilated by selection S. Hence equality of ideal row spaces does not imply retention of all noise, artifacts or discriminative information of real data. The17-channel input does not reconstruct that edge or inject its noise bound as a model term. Its clinical adequacy requires a separate development comparison under the frozen protocol; it is not called optimal. This is conditional instrument linear algebra, not a BFG-internal physical law or a solution of physiological preparation.
