Acceptance criteria fixed before implementation: original summary and binary companion must match the original master checksum list, which itself matches the pinned digest; exact record must be development-only and belong to the case; all numerical boundaries/counts/sample rate must agree with binary; every proposed identity change must be explicitly named and actually needed; originals remain unchanged. Unexpected source changes or discrepancies reject. No silent exception in parse_summary.

annotation_reconciliation.boundary_subset is a deliberately restricted WFDB decoder for the audited metadata NOTE/AUX, declared positive sampling rate, exact metadata reset and alternating32/33 boundary sequence. It checks word/payload/padding/terminal bounds, signed PDP-11 SKIP ordering, nonnegative event increments and nonempty ordered intervals. Unsupported variants fail. It is not a general WFDB replacement and does not interpret clinical labels beyond this previously verified boundary convention. Specification and earlier WFDB4.3.0 source hashes remain in BINARY_ANNOTATION_CROSSCHECK.md/binary_annotation_crosscheck.json.

reconcile_block compares every source unsigned-integer time times the declared sample rate exactly against the binary sample position. Source count must equal binary pair count. Approval entries explicitly identify(pair position,Start/End,old identity). Only a mismatching numeric ID token may be replaced by its pair position; absent/stale/duplicate approvals, changed boundaries or unknown syntax reject. reconcile_summary first checks exact development membership, source/case identity and original source/binary/master hashes, locates the unique source block, checks source rate, and applies that transformation to an in-memory copy while preserving every other line/byte. Return receipt records source/binary/derived hashes and changed-token count; neither original file is overwritten.

Proof scope: exact array equality establishes consistency of numerical representations, not expert seizure truth, onset uncertainty, per-record EDF duration or anatomy. Hash matching binds bytes to the audited source, not clinical correctness or trust in the original publisher. Explicit approval is an auditable preparation choice justified by the independent binary evidence, not a universal numbering repair. Broader variants, extra metadata or unknown numbering errors remain rejected. No automatic file exclusion or event deletion. A source whose boundaries disagree with the binary needs separate investigation, never a label-only repair.
