# BFG Claim Register

## Balance–Field Framework (BFG)

This register records the epistemic status of major claims, definitions, constructions, simulations, and empirical hypotheses within the **Balance–Field Framework (BFG)**.

Its purpose is to prevent different levels of scientific assertion from being merged.

A mathematical definition is not automatically an empirical result.

A theorem-level result is valid only under its declared assumptions.

A simulation is not empirical confirmation.

A cross-domain reconstruction is not evidence of universality merely because the same vocabulary can be applied in several domains.

A failed claim remains part of the research record.

---

# 1. Claim-State Principle

Every substantive BFG claim should be assigned a declared claim state before it is treated as part of the research core.

The Balance-Field Standard uses claim-state classification as an admissibility condition.

A claim that is not classified should not be transported into the BFG core as established knowledge.

The primary claim states are:

| Claim State                      | Meaning                                                                            |
| -------------------------------- | ---------------------------------------------------------------------------------- |
| **Level-0 Origin Basis**         | Foundational admissibility structure used as BFG origin grammar                    |
| **BFG Core Structure**           | Stable structural architecture used across BFG work                                |
| **Mathematical Definition**      | Formally declared variable, operator, metric, predicate, or relation               |
| **Theorem-Level Claim**          | Result following from declared assumptions and definitions                         |
| **Ansatz-Level Construction**    | Proposed mathematical or conceptual construction awaiting stronger validation      |
| **Simulation / Model**           | Synthetic or computational implementation                                          |
| **Empirical Hypothesis**         | Externally measurable prediction requiring data                                    |
| **Established External Science** | Independently established scientific result used as an external boundary or anchor |
| **Speculative Extension**        | Proposal that extends beyond current formal or empirical support                   |
| **Redescription-Only**           | Mapping that currently adds no demonstrated constraint beyond existing terminology |
| **Rejected / Failed**            | Claim that did not pass its declared test or falsification gate                    |
| **Open**                         | Claim whose current evidence is insufficient for acceptance or rejection           |

---

# 2. Claim Transport Rule

A claim may be transported into the BFG research core only when its relevant boundaries are declared.

The compact transport principle is:

**Transport(x) = Accept**

only when the following are identified:

**claim state**

AND

**source**

AND

**BFG roles**

AND

**falsification condition**

AND

**interpretation boundary**

For strong empirical claims, additional requirements include:

**operational readout**

AND

**null models**

AND

**ablation**

AND

**no-retuning**

AND

**failure preservation**

# 4. Order and Information Claims

## BFG-CR-010 — BFG Order Parameter Φ

**Claim**

BFG defines a dimensionless balance parameter relating expansive drive, binding drive, and structured information.

**Status**

**BFG Core Structure + Mathematical Definition**

**Definition**

**Φ = (Eexp · I) ÷ (Ebind · I0)**

where:

* `Eexp` = expansive or dispersive drive,
* `Ebind` = binding or stabilizing drive,
* `I` = structured information,
* `I0` = reference information scale.

**Dimensional condition**

**[Φ] = 1**

**Regimes**

**Φ < 1 → binding-dominated**

**Φ = 1 → balanced**

**Φ > 1 → expansion-dominated**

For empirical systems:

**Φ ≈ 1**

may represent an operational balance corridor.

**Interpretation boundary**

Φ is a balance diagnostic.

Φ ≈ 1 does not by itself establish BFG closure or empirical confirmation.

# 8. Falsification and Audit Claims

## BFG-CR-021 — Redescription Null Model

**Claim**

A BFG reconstruction that only renames already-known structures does not demonstrate BFG-specific scientific added value.

**Status**

**BFG Methodological Core**

**Primary null**

**Redescription-only**

Examples:

* existing interaction → mediation,
* existing stability → closure,
* existing output → export,
* existing attractor → BFG attractor.

**Pass condition**

BFG must add measurable constraints, predictive discrimination, ablation sensitivity, failure localization, or transferable structure.

# 11. Claim Decision States

Each registered claim may receive one of the following decision states:

| Decision                 | Meaning                                                          |
| ------------------------ | ---------------------------------------------------------------- |
| **Admissible**           | Claim currently satisfies its declared BFG gate                  |
| **Partially Admissible** | Some required conditions are supported but others remain open    |
| **Open**                 | Evidence is insufficient for acceptance or rejection             |
| **Restricted**           | Claim is valid only in a narrower scope than originally proposed |
| **Rejected**             | Claim failed its declared test                                   |
| **Falsified**            | Strong declared falsification criterion has been met             |
| **Redescription-Only**   | No BFG-specific added value currently demonstrated               |

# 13. Register Governance

This register should not be silently rewritten when a claim changes status.

If a claim moves from:

**Open → Admissible**

or

**Open → Rejected**

the previous state should remain recoverable through repository history.

A claim should receive a new version or documented status change rather than having its scientific history erased.

# 15. Guiding Rule

> **No claim becomes stronger merely because it has been repeated in more BFG documents.**

A claim becomes stronger only when its:

* assumptions are clearer,
* operationalization is sharper,
* null models are stronger,
* ablations are more decisive,
* predictions survive held-out testing,
* transfer survives without retuning,
* and independent evidence accumulates.

The purpose of this register is therefore not to maximize the number of accepted BFG claims.

Its purpose is to keep the scientific status of every major claim visible, auditable, and falsifiable.
